Color Rules
Burning Orange — One primary CTA per screen maximum. Never as a text color. Never as a large background.
Deep Sea Green — All static UI chrome: labels, headings, nav text, secondary buttons. Never for user-entered data.
Deep Peach — 1.5px border on Active Ping cards only. Never for buttons, text, or anything else.
Off-white #F7F9FA — Page background only. Creates depth without shadows. Never use on components.
White #FFFFFF — Cards, modals, inputs — all surfaces that sit on top of the off-white page background.
Black #1A1A1A — All dynamic content: names, values, user-typed text. Never use pure #000000.
Mid Gray — Placeholder text, timestamps, metadata, helper text only. Never for primary data.
Destructive Red — Delete, Deny, Remove actions only. Never for cancel buttons.
⚠️ Never place a Burning Orange button and a Deep Sea Green button side by side — the contrast clash competes for attention.

05 — Components

Buttons

Four variants only. Never create a fifth. All use Lexend body-medium (14px / 500).

Four Variants
Primary — Burning Orange
Background: #FD703B · Text: White · Radius: 6px · Padding: 8px 16px
One per screen maximum. The single most important action.
Secondary — Deep Sea Green
Background: #145364 · Text: White · Radius: 6px · Padding: 8px 16px
Important non-primary actions: Archive, Calendar, navigation.
Outline — Matched to primary pair
Transparent bg · 1px border matching pair color · Text matches border
Always paired with a filled button. Use for cancel/secondary choices.
Destructive — Red
Transparent bg · 1px border #DC2626 · Hover: fills red
Delete, Deny, Remove only. Never for cancel actions.
Button Pairings
Primary + Cancel (orange pair)
Secondary + Cancel (green pair)
Approve / Deny pair
⚠️ Never place Primary (orange) and Secondary (green) buttons side by side — they clash.
